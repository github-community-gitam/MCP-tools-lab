availability and completion status. Issue numbers on GitHub may differ from filenames.

2. [Choose JSON indentation](02-json-indentation.md) — beginner
3. [Uppercase hashes](03-uppercase-hashes.md) — beginner
4. [Preview CSV rows](04-csv-preview.md) — beginner–intermediate
5. [Count unchanged lines](05-unchanged-lines.md) — beginner
6. [Support Unix milliseconds](06-milliseconds.md) — beginner–intermediate
7. [Count characters excluding whitespace](07-non-whitespace-count.md) — beginner
8. [Report empty CSV column names](08-empty-csv-headers.md) — beginner–intermediate
9. [Support semicolon and tab CSV delimiters](09-csv-delimiters.md) — beginner–intermediate
10. [Add case-insensitive text comparison](10-ignore-case-diff.md) — intermediate
11. [Show the UTC weekday](11-utc-weekday.md) — beginner
12. [Count URL query parameter entries](12-query-count.md) — beginner

Read [contributions.md](../../contributions.md) first. Each task names the files to
edit and includes acceptance criteria. These are optional enhancements, not broken
features that you must fix before the project can run.
